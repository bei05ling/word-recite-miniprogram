# 页面结构

## 核心流程

| 页面 | 路径 | 职责 |
| --- | --- | --- |
| 今日学习 | `pages/index/index` | 今日目标、当前词书、每日词签和快捷入口 |
| 探索词书 | `pages/library/library` | 四本主题词书、每日词签、词书进度 |
| 查词 | `pages/search/search` | 中英文全文检索与词书筛选 |
| 单词详情 | `pages/word-detail/word-detail` | 音标、音节、例句、关联词和复习操作 |
| 学习单词 | `pages/study/study` | 单词卡翻面、切词、TTS 和掌握状态 |
| 拼写测试 | `pages/quiz/quiz` | 题目生成、即时判分和错词记录 |
| 错词复习 | `pages/mistakes/mistakes` | 到期错词和间隔复习状态机 |
| 学习统计 | `pages/stats/stats` | 正确率、连续学习和最近七天活动 |
| 成就档案 | `pages/achievements/achievements` | 等级进度、近四周日历和八项成就 |
| 收藏本 | `pages/notebook/notebook` | 收藏词管理、跨词书归类和词条回看 |
| 个人中心 | `pages/profile/profile` | 个人资料、跨词书进度、成就和偏好 |

## 主要跳转

```text
首页
├─ 查词
│  └─ 单词详情
├─ 探索词书
│  ├─ 查词
│  └─ 开始学习
├─ 今日词签 → 单词详情
├─ 单词卡 → 完整词条
├─ 收藏本 → 单词详情
└─ 个人中心
   ├─ 成就档案
   ├─ 探索词书
   ├─ 查词
   ├─ 收藏本
   ├─ 学习统计
   └─ 错词复习
```
